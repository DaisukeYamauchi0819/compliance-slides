Opening コンプラ違反で何が起きるか 02 / 26

実際に起きていること

金融庁・各都道府県は毎年、保険代理店への行政処分を実施しています。

主な処分内容

  • 業務停止命令（数日〜数ヶ月）
  • 登録取消し（＝廃業）
  • 代理店を経由した募集人の登録抹消

違反原因ランキング

1 禁止行為（虚偽説明・不利益不告知）
2 意向把握の未実施
3 無登録者による保険募集
⚠️ 3位の無登録募集は、皆さんが依頼する側になるリスクがあります。登録前のスタッフに何かを頼むことも違反になります。

Module 2 禁止行為とは（保険業法第300条） 08 / 26

募集人が絶対にやってはいけない行為

保険業法第300条に定められた、最も重要なルールです。

行政処分

業務停止・登録取消し

民事

顧客との損害賠償トラブル

刑事罰

最大1年の懲役

「知らなかった」は通用しない

Module 2 禁止行為① 虚偽説明・断定的判断の提供 09 / 26

NG例：事実と異なる説明

  • 「この保険は元本保証です」（変額保険なのに）
  • 「保険料は変わりません」（更新型なのに）
  • 「解約返戻金が払込保険料を下回ることはない」

NG例：断定的判断の提供

  • 「銀行より絶対に有利です。絶対に損しません」
  • 「将来必ず保険金が受け取れます」

ポイント

  • 不確実なことは「可能性があります」と表現する
  • わからなければ「確認します」と答える
Module 2 禁止行為② 不利益事実の不告知・重要事項の不説明 10 / 26

NG例：不利益の隠蔽

  • 解約返戻金が下がることを言わずに乗換えを勧める
  • 更新時に保険料が上がることを説明しない

NG例：重要事項の不説明

  • 免責期間があるのに「いつでも保険金が出ます」
  • 対象外の手術があるのに「どんな手術でも支払い対象」

ポイント：有利・不利の両方を、省略せず正直に伝えることが義務

Module 2 禁止行為③〜⑤ 11 / 26

③ 誤解させるおそれのある比較・説明

  • 「業界No.1の実績」（何がNo.1か不明確）
  • 保険料の安さだけ強調した比較資料で「うちが一番優れている」

✅ 比較には客観的根拠が必要。一部条件のみ切り取った強調は禁止

④ 不当乗換勧誘

  • 不利益を説明せずに「今の保険は古いので入り直しましょう」

✅ 不利益を十分説明した上で顧客が納得して選択した場合はOK。面談記録に残す

⑤ 告知義務違反の唆し

  • 「持病のことは書かなくていいですよ」「その病歴は省略して」

→ 顧客の契約解除・保険金不払い・代理店も処分対象

Module 2 禁止行為⑥〜⑨ 12 / 26

⑥ 特別利益の提供（2025年改正で強化）

  • 初月保険料の立替・ギフト券の進呈・保険料の一部自腹負担
  • 不必要に高額な飲食接待（契約獲得が目的）

✅「好意」のつもりでも違反。自腹かどうかも関係なし

⑦ 威迫・業務上の地位の不当利用

  • 「今日決めてもらわないと困ります」／断られても何度も連絡
  • 「保険に加入しないなら今後の取引を考え直す」と示唆する

⑧ 誹謗・中傷　／　⑨ 保険種類・保険会社の誤認

  • 競合会社の格付け記事を渡して劣位を強調（渡すだけでも違反）
  • A生命と言いながらB生命を販売する／代理店名と保険会社名を混同させる

④

⑤
告知義務違反唆し

⑥
特別利益の提供

⑦
威迫・地位の不当利用
断れない状況・取引関係を使った強要は禁止
⑧
誹謗・中傷
記事コピーを渡すだけでも違反になりうる
⑨
保険種類・会社誤認

Module 3 保険募集の5ステップ（必ずこの順番で） 15 / 26
1

意向把握

加入目的・予算・家族構成・既契約をヒアリング・記録

特定商品への誘導禁止

2

商品選定

意向に基づき複数商品を比較・検討

推奨理由を明確に記録する義務あり

3

保障内容・免責・解約控除・リスクを正確に説明

意向確認書に署名・その場で保管

5

💡 先に商品を決めてから意向を合わせることは法令違反です。必ずSTEP 1から順番通りに進めてください。次のページから各ステップを詳しく解説します。
Module 3 STEP 1 — 意向把握

目的：顧客が本当に必要とする保障を先入観なく把握する

必ず確認する項目

  • 加入目的（死亡保障・医療・老後・教育資金など）
  • 月々の予算・支払い可能な保険料
  • 家族構成・扶養関係
  • 現在加入中の保険の内容
  • 健康状態の概要（告知に関わる部分）

NG — 特定商品への誘導

  • 「どうせ〇〇保険が必要でしょ」と先に商品を決める
  • 意向を聞かずに設計書を作って持参する

記録のポイント

  • 面談記録シートにヒアリング内容を記載
  • 顧客の言葉でニーズを記録（自分の解釈で書かない）
Module 3 STEP 2 — 商品選定

目的：ヒアリングした意向をもとに、最も適切な商品を選ぶ

選定の基準

  • 顧客の意向・ニーズに合っているか
  • 予算に合う保険料か
  • 推奨理由を明確に説明・記録できるか

⚖️ 比較推奨販売（乗合代理店）

  • 複数社の商品を必ず比較検討する
  • 推奨理由を書面で提示・記録（2025年改正）
  • 利益相反（手数料優先など）は顧客に開示する

NG — 会社都合の選定

  • 手数料が高い商品を顧客ニーズより優先する
  • 比較検討なしに「これがおすすめ」と提示する
  • 推奨理由を記録しない・顧客に説明しない

記録のポイント

  • 比較した商品名・会社名と推奨理由を書面に残す
  • 利益相反がある場合はその旨を記録・開示する
Module 3 STEP 3 — 商品説明

目的：顧客が十分に理解した上で判断できる環境を作る

必ず説明・交付する内容（保険業法第294条）

  • 契約概要：保障内容・保険料・解約返戻金
  • 注意喚起情報：免責事項・告知義務・クーリングオフ
  • 推奨理由（乗合代理店は必須）
  • 書面または電子交付のどちらかで必ず渡す

NG — 不完全な説明

  • メリットだけ説明しデメリットを省く
  • 書類を「渡すだけ」で内容を説明しない
  • 交付漏れ・説明記録なし（重大違反）

記録のポイント

  • 「説明した」という記録を面談記録に残す
  • 顧客の理解・質問内容も記録する
Module 3 STEP 4 — 意向確認

目的：顧客の意向と契約内容が一致しているかを最終確認する

確認すべきこと

  • STEP 1でヒアリングした意向と、選んだ商品の内容が合っているか
  • 顧客が商品の内容を正しく理解しているか
  • 意向確認書に顧客の署名をもらう
  • 署名は面談その場で行い、持ち帰りは原則NG

NG — 形式だけの確認

  • 意向確認書を後日郵送してサインをもらう
  • 「とりあえずサインして」と内容説明なし
  • 意向と商品内容が合っていないのに進める

記録のポイント

  • 意向確認書は署名後すぐに保管
  • 内容変更があれば再度確認・再署名が必要
Module 3 STEP 5 — 契約締結

目的：適正な申込み・告知取得を行い、契約を正式に成立させる

契約締結時にすること

  • 申込書の記入内容を顧客と一緒に確認する
  • 告知書は顧客自身に正確に記入してもらう
  • クーリングオフ制度を必ず口頭で説明する（8日間）
  • 約款を交付する（電子交付可）

NG — 告知義務違反の唆し

  • 「この病歴は書かなくていいですよ」と誘導する
  • 顧客の代わりに告知書を記入する
  • クーリングオフの説明を省く

記録のポイント

  • 申込書・告知書のコピーを保管
  • クーリングオフ説明をした旨を記録に残す
Module 3 情報提供義務 & よくあるNG例 16 / 26

必ず渡して説明する書類（保険業法第294条）

  • 契約概要：保障内容・保険料・返戻金等
  • 注意喚起情報：告知義務・クーリングオフ・免責事項等
  • 推奨理由（複数商品取扱の場合）
⚠️ 渡すだけでなく「説明した」という記録が必要。
書面・電子どちらでも交付漏れは重大違反

よくあるNG例

NG① 良いところだけ説明して申込みをもらう

→ 注意喚起情報（デメリット）の説明が必要

NG② 「とりあえず申込書だけ書いてもらった」

→ 意向把握が先、申込みは後

NG③ 意向確認書を後日郵送した

→ 説明と同時に交付・確認が原則

NG④ 顧客の意向を聞かずに「これがおすすめ」

→ STEP 1（意向確認）が必ず先

Module 4 保険業務で扱う個人情報の特殊性 17 / 26

通常の個人情報

  • 氏名
  • 住所
  • 電話番号

＋ 要配慮個人情報

  • 病歴・健康状態
  • 身体的特徴

要配慮個人情報は：

  • 取得に本人の明示的な同意が必要
  • 漏洩した場合のリスクが特に高い
  • 第三者提供は原則禁止（同意なし不可）

「一般的な個人情報よりも厳格に扱う」

Module 4 日常業務での個人情報ルール 18 / 26

📄 書類・資料

  • 顧客情報が入った書類は鍵付き保管
  • 廃棄するときは必ずシュレッダー
  • 他の顧客に見えるところに置かない

PC・スマートフォン

  • 画面ロックを必ず設定する
  • 会社支給デバイスのみ使用
  • 個人クラウドに保存しない（Googleドライブ等）

🚶 外出時

  • 持ち出し記録をつける
  • 電車・カフェで顧客情報を声に出さない
  • 資料を鞄から出したまま席を離れない

LINE・SNS

  • 個人LINEで契約情報・保険料を送らない
  • 申込書の写真をLINEで送受信しない
  • 顧客名・情報をSNSに投稿しない（仮名もNG）
  • 「今日〇〇さんの契約が取れた」もNG
Module 4 情報漏洩が起きたら 19 / 26
1
すぐに上長・内部管理責任者に報告
自分だけで判断しない。即時報告が最優先
2
状況を記録（いつ・何が・どのように）
正確に記録することで被害状況と範囲を把握する
3
被害を広げない行動
関係するデバイスを隔離する等
4
会社の指示に従って対応

確認テスト 解答・解説 — 問1〜4

問1　顧客から「友人を紹介したらキャッシュバックしてもらえますか？」と聞かれ、「商品券を差し上げます」と答えた。

× NG

顧客への金品・サービスの提供は「特別利益の提供」として保険業法で禁止。紹介者への謝礼も同様。

問2　顧客から「この保険、絶対に元が取れるよね？」と聞かれ、「はい、絶対お得ですよ！」と断言した。

× NG

将来の受取額や運用結果を「絶対」と断定することは禁止行為。「ご契約条件によります」と正確に説明する。

問3　顧客が他社保険から乗換えを希望した。解約返戻金が減少する旨を事前に説明した上で乗換えを提案した。

○ OK

不利益事項を十分説明した上での乗換え提案はOK。禁止されているのは「説明せずに」勧めること。

問4　顧客から「持病があるんだけど、告知書には書かなくてもバレないよね？」と相談され、「必ず正確に記載してください」と伝えた。

○ OK

正確な記載を促すのが正しい対応。「書かなくていい」と誘導することが告知義務違反の唆しとなり禁止行為。

○ OK

病歴・健康状態は「要配慮個人情報」。第三者提供には本人の明示的な同意が必要で、同意があれば提供できる。

確認テスト 解答・解説 — 問8〜10

問8　顧客から「今入っている保険でがんになったらいくら出るの？」と聞かれたが、手元に契約内容が確認できない。

A. 「おそらく100万円くらいだと思います」と概算で答えた B. 「分かりません」とだけ答えた C. 「証券番号を確認して折り返しご連絡します」と伝えた ✅ D. 「がんより死亡保障も見直しませんか？」と話題を変えた

不正確な情報提供も「分からない」で終わることも不誠実。確認の上、正確な情報を提供することが顧客対応の基本。

問9　顧客から「A社とB社、どちらの保険がいいか比べて選んでほしい」と依頼された。乗合代理店として最も適切な対応は？

A. 手数料が高いA社を優先してすすめた B. 顧客のニーズをヒアリングし、両社の特徴と推奨理由を書面で示した ✅ C. 「どちらも同じようなものです」と答えた D. 「人気が高いのでB社がおすすめです」と伝えた

乗合代理店は複数社を比較検討し、顧客ニーズに合った推奨理由を書面で示す義務がある。手数料優先の提案は禁止。

問10　顧客が「少し考えさせてください」と言った。スタッフとして最も適切な対応は？

A. 「今日中に決めると特別割引が適用されます」と急かした B. 「承知しました。ご不明点があればいつでもご連絡ください」と伝えた ✅ C. 「他のお客様もすぐ決めていますよ」と言って焦らせた D. 「今決めないと損をしますよ」と圧力をかけた

顧客が検討を希望している場合に急かすことは不当勧誘。A・C・Dは断定的判断や威迫にあたり保険業法違反。

Module 5 改正① 顧客本位の業務運営の法定化

2025年施行 — 顧客の「最善利益」が法的義務へ

フィデューシャリー・デューティー（顧客本位の業務運営）が、努力義務から法令上の明確な義務に。代理店は商品選定理由・利益相反の状況を顧客に開示し、記録する必要がある。

NG例

  • 手数料が高いから優先して提案する
  • 利益相反の状況を顧客に開示しない

OK例

  • 商品選定理由を文書で記録
  • 複数商品を比較した提案
  • 利益相反は事前に開示
⚠️ 「手数料が高いから勧める」だけでは法令違反になりうる時代へ
Module 5 改正② 乗合代理店の比較推奨ルール強化

複数の保険会社を扱う乗合代理店は、特定商品への誘導が禁止。推奨理由の明示と記録が義務化される。

推奨理由の明示

なぜその商品を選んだかを顧客に必ず説明

比較説明の記録

他社商品との比較プロセスを文書化

手数料開示

代理店手数料の開示義務化が検討中

❌ 「○○生命だけ勧めるのは、手数料が高いからです」——これは不適切とみなされる可能性あり

SNS・DM・メッセージアプリでの募集行為に明確なルール。個人発信は社内承認が必須。
